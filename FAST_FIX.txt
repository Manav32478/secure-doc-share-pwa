⚡ FAST FIX - DO THIS NOW ⚡
================================

YOUR PROBLEM: Documents uploading but not showing

THE FIX: Copy-paste these rules into Firebase Console

⏱️ TIME: 2 minutes


STEP 1: FIRESTORE RULES
------------------------
1. Open: https://console.firebase.google.com/project/doc-share-55636/firestore/rules
2. DELETE EVERYTHING
3. PASTE THIS:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

4. Click "PUBLISH" button
5. Wait 5 seconds


STEP 2: STORAGE RULES
----------------------
1. Open: https://console.firebase.google.com/project/doc-share-55636/storage/rules
2. DELETE EVERYTHING
3. PASTE THIS:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null;
      allow write: if request.resource.size < 50 * 1024 * 1024;
    }
  }
}

4. Click "PUBLISH" button
5. Wait 5 seconds


STEP 3: REFRESH
---------------
Go to: http://localhost:8000/dashboard.html
Press: Cmd+R (or Ctrl+R)

✅ DONE! Your documents will now show!


IF IT STILL DOESN'T WORK:
-------------------------
1. Check Firestore exists: https://console.firebase.google.com/project/doc-share-55636/firestore
   - If you see "Get started", click it → "Test mode" → Enable
2. Check Storage exists: https://console.firebase.google.com/project/doc-share-55636/storage
   - If you see "Get started", click it → "Test mode" → Done
3. Check Auth enabled: https://console.firebase.google.com/project/doc-share-55636/authentication/providers
   - Enable "Email/Password"
4. Refresh dashboard again
