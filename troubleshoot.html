Getting Started with SecureVault

To fully activate all features and ensure documents display correctly, follow these setup steps:

1 Open Firestore Rules

Navigate to the Firebase Console and access the Firestore rules editor

Open Firestore Rules
2 Replace Firestore Rules

Delete all existing rules and paste the following configuration:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } }
3 Publish Firestore Rules

Click the Publish button at the top and wait for the success message

4 Update Storage Rules

Navigate to Storage rules and apply the following configuration:

Open Storage Rules
rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /{allPaths=**} { allow read, write: if request.auth != null; allow write: if request.resource.size < 50 * 1024 * 1024; } } }
5 Publish Storage Rules

Click Publish and wait for confirmation

6 Verify Setup Complete

Return to your dashboard and refresh the page

Return to Dashboard
✅
Verification Checklist

After completing the setup above, verify these items are working:

  • Firebase Console shows "Rules published successfully"
  • Dashboard displays all previously uploaded documents
  • Can upload new documents and see them immediately
  • Can download documents using the download button
  • Can generate shareable links with expiration dates
  • Browser console shows no "permission denied" errors
🔧
Additional Setup Verification
Check 1: Firestore Database Created
  1. Go to Firestore Database
  2. If you see "Get started", click it
  3. Select "Start in test mode"
  4. Choose location (us-central or nearest to you)
  5. Click Enable
Check 2: Storage Enabled
  1. Go to Cloud Storage
  2. If you see "Get started", click it
  3. Select "Start in test mode"
  4. Use the same location as your Firestore database
  5. Click Done
Check 3: Authentication Enabled
  1. Go to Authentication
  2. If you see "Get started", click it
  3. Go to "Sign-in method" tab
  4. Enable "Email/Password"
  5. Click Save
🐛
Debugging Tips

Press F12 → Console tab to check for these messages:

✓ Good Messages (Everything Working):
Loading documents for user: abc123xyz Documents found: 1 Document data: {fileName: "file.pdf", ...}
✗ Error Messages (Needs Attention):
FirebaseError: Missing or insufficient permissions FirebaseError: permission-denied

If you see these errors, return to Steps 1-5 above and verify the rules were updated correctly.

🎉
After Setup: Using SecureVault Features

Once documents display properly, here are the main features available:

📤 Upload Documents
  1. Go to the Dashboard
  2. Click the "Upload" area or drag files
  3. Select one or multiple documents (PDF, Word, Images, etc.)
  4. Files are automatically encrypted and stored securely
📧 Email Sharing
  1. Find any document in your dashboard
  2. Click the Share button
  3. Enter recipient's email address
  4. Set an expiration date/time
  5. Click "Share" - recipient gets email notification
  6. Access automatically expires at the set time
🔗 Generate Shareable Links
  1. Scroll to "Generate Shareable Link" section
  2. Enter hours until expiration (e.g., 24 hours)
  3. Click "Generate Link"
  4. Copy the generated link and share it
  5. Anyone with the link can download (no login needed)
  6. Link automatically expires after the time period
🔒 Security Information: The rules above are development-mode rules that allow authenticated users to read/write documents. For production deployments, see firestore.rules and storage.rules files for more restrictive rules. Deploy using Firebase CLI: firebase deploy --only firestore:rules,storage:rules
